# Mr.I's Emoji World 🌈

A fun interactive website that simulates Mr.I's unique communication style! This website responds to your messages with random emojis and has a special dancing emoji feature when you express frustration.

## Features

- Chat-like interface
- Random emoji responses
- Dancing emoji animation when you express frustration
- Responsive design
- Fun animations and transitions

## How to Use

1. Open `index.html` in your web browser
2. Type your message in the input field
3. Press Enter or click the Send button
4. Watch Mr.I respond with random emojis!
5. Try expressing frustration to see the dancing emoji feature

## Technical Details

- Built with vanilla HTML, CSS, and JavaScript
- No external dependencies required
- Responsive design works on all devices
